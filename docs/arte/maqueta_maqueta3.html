295 usos

C -- EL MOVIMIENTO

193 usos

CSS anima maquetando en cada cuadro. MAQUETA no maqueta en el aparato: anima ESTADOS ya maquetados.

CSS

@keyframes latido {
  50% { transform:scale(1.18) }
}
.punto { animation:
  latido 1.6s infinite }

MAQUETA 3

@secuencia latido 1600ms
          repite {
  50% { .punto { width:40px;
                 height:40px } }
}

cada paso de la secuencia es un @estado ENTERO: se maqueta y se juzga al compilar (un texto que no cabe en el 50 % no compila). El aparato solo mezcla piezas, como hoy con las transiciones.

CSS

transform: translateY(-4px)
           scale(1.05);
transform-origin: center;

MAQUETA 3

@estado arriba {
  .carta { transform:
    translateY(-4px) scale(1.05) }
}

solo dentro de un estado o de una secuencia, y resuelto a cajas de pixel entero al compilar: la "carta que sube" se ve igual en el navegador y en el Ryzen. Rotar se rechaza: la letra de la casa no se pinta torcida.

NUNCA (Y LOS SUELTOS) -- 183 usos, y por que

  • inherit, herencia (23): un padre no sabe que tiene padre (L7). Se escribe var(--x).
  • width: %, height: auto, calc() (60): piden la medida del contenedor. fr de la rejilla PROPIA lo cubre.
  • content, pseudo-elementos (10): una caja que no esta en el fichero no se puede juzgar.
  • filter, mix-blend-mode, mask, clip-path (13): piden componer en el aparato. El desenfoque es de la 3060 (VERRANO), no de la maqueta.
  • decimales de caja (line-height:1.4, font-size:13.5px, 19): medio pixel de caja es un borde borroso.
  • restos de JavaScript y prefijos -webkit- (5): no son CSS.
  • y 53 sueltos de 1 a 7 usos (overflow-wrap, background-size, stroke-dasharray, sticky...): no son "nunca" -- se miran uno a uno cuando un caso real los pida.
