# LEYES DE TITAN++ -- lo que el lenguaje NO cambia sin una decision del propietario.
#
# El propietario, 04-10: *"tener guardian estricto el TITAN++ que no se altere,
# con reglas y porque"*. Cada ley dice TRES cosas, y el guardian
# (`titan_leyes.py`) comprueba las tres en cada build:
#
#     ley       lo que el lenguaje promete, en una linea
#     porque    por que lo promete: de donde viene, que fallo evita
#     cumple    QUIEN la hace cumplir hoy, y tiene que seguir vivo:
#                   test RUTA FUNCION   un test que existe y no esta ignorado
#                   ejemplo T00NN       un programa del banco que provoca ese NO
#
# ** Una ley no se escribe aqui para adornar: si su `cumple` desaparece (el test
# se borra, se ignora, o el ultimo ejemplo de ese codigo se va), el build para.
# Y si el TEXTO de una ley cambia, tambien: el sello de abajo es la huella de
# todas, y moverlo es `titan_leyes.py --sellar "el motivo"`, que deja el
# motivo en la HISTORIA. Una ley se cambia a la vista, nunca de paso.
